## STEP 2: Open Chrome Extensions Page

1. Open your **Google Chrome** browser.
2. In the URL address bar at the top, **copy-paste the following link** and press **Enter**:

```
chrome://extensions/
```

---

## STEP 3: Turn on Developer Mode

1. Look at the **TOP RIGHT corner** of the extensions page.
2. Find the switch that says **"Developer mode"** and turn it **ON** (it will turn blue).

```
┌─────────────────────────────────┐
│                    [Developer mode] ◄── Turn ON (blue)
│                         ○       │
└─────────────────────────────────┘
```

---

## STEP 4: Load the Extension

1. Look at the **TOP LEFT corner** of the page and click the button:
   
   **"Load unpacked"**

3. **Select the unzipped folder** containing the extension files (the whole `aliexpress2_spy-PLUGIN-EN` folder).

4. Click **"Select Folder"** or **"Open"**.

## ✅ Troubleshooting

### Issue: "Error: Failed to load extension"

**Solution:**
- Verify you extracted the ZIP file completely
- Make sure the folder contains these files: `manifest.json`, `content.js`, `background.js`, `popup.html`, `popup.js`
- Try refreshing the extensions page (Ctrl+R or Cmd+R)

### Issue: Buttons not showing on AliExpress

**Solution:**
- Refresh the AliExpress page (Ctrl+F5 or Cmd+Shift+R for hard refresh)
- Check extension is enabled (blue toggle next to extension name)
- Try a different product search page

### Issue: "Cannot activate license key"

**Solution:**
- Verify you copied the license key correctly (no extra spaces)
- Check your internet connection
- Make sure the key hasn't expired (check LemonSqueezy email)

### Issue: Limited to 3 free checks

**Solution:**
- This is intentional! Free version has 3 trial uses per day
- Subscribe to Premium to get unlimited checks
